# Гонка Наций: интерактивная игра для TikTok LIVE

Шесть машинок с флагами — 🇰🇿 Казахстан, 🇷🇺 Россия, 🇺🇦 Украина, 🇦🇲 Армения, 🇦🇿 Азербайджан, 🇹🇷 Турция — гонятся
к финишу. Зрители двигают свою страну подарками, лайками и комментариями. Раунд — 3 минуты, последние 30 секунд —
**ФИНАЛ ×2**, все эффекты удваиваются.

## Запуск одной командой

```bash
cd ~/Desktop/Celebrity-game-
git checkout -- package-lock.json config.json && git pull && npm install   # обновление (один раз)
npm run live -- narezki.filmov66
```

Команда запускает игру **и** туннель cloudflared и крупно печатает адрес вида `https://….trycloudflare.com`.
Если cloudflared ещё не скачан, положите его в папку игры (на Mac с процессором M1/M2/M3):

```bash
curl -L -o cloudflared.tgz https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-darwin-arm64.tgz
tar -xzf cloudflared.tgz && chmod +x cloudflared
```

Без туннеля: `npm start -- ВАШ_НИК`, оверлей на `http://localhost:3000/`.

## Как добавить в TikTok LIVE Studio

1. Вверху над источниками выберите **вертикальный** режим (иконка телефона).
2. **Add source → Link** → вставьте адрес из Терминала (`https://….trycloudflare.com`).
3. Разрешение **Custom 1080×1920**, включите **Turn on sound** и **Always keep active**.
4. Растяните источник на весь кадр — игра рассчитана на эфир без ведущего в кадре.
5. В Терминале должна появиться строка `[оверлей] подключился`. Если адрес туннеля поменялся (после перезапуска) — удалите
   старый Link и добавьте новый.

Звук: в LIVE Studio он играет сразу. В обычном браузере — после первого клика по странице.

## Панель стримера (в эфир не идёт)

`http://localhost:3000/panel` — открывается только на компьютере стримера (через туннель — нельзя):
- **Старт / пауза / сброс раунда**, длительность раунда и финала, шипы и масло вкл/выкл, громкость, FPS оверлея, озвучка «Спасибо, Nar, за ракету!»;
- **уровни подарков** — пороги в монетах и сила эффекта;
- **симулятор** — подарок N монет от ника X за страну Y, лайки, коммент, подписка, репост, вход; **стресс-тест** 50 подарков за 10 с;
- статус подключения к TikTok, **лог всех подарков** и **победы стран за день**.

## Как играть (для зрителей)

- **Вступить в команду** бесплатно: написать в чат флаг (🇦🇲) или код/название: `am`, `арм`, `армения`, `hayastan`
  (kz/кз/казахстан/qazaqstan, ru/рф/россия/russia, ua/укр/украина/ukraine, az/азер/азербайджан/azerbaijan,
  tr/тур/турция/türkiye). Код засчитывается, только если сообщение состоит из него («I am here» не запишет за Армению).
  Выбор держится всю трансляцию.
- **Подарок без команды** уходит стране на последнем месте («Nar спасает 🇰🇿!»), и зритель закрепляется за ней.
- **Атака по выбору:** `атака ru` в чате → следующая ракета полетит в эту страну.

| Монеты (цена × количество) | Эффект |
|---|---|
| 1–4 | 🔥 **Нитро** — рывок |
| 5–9 | ⚡ **Турбо** — сильный рывок |
| 10–29 | 🛡️ **Щит** на 20 с — защита от ракет, хаоса, шипов и масла |
| 30–99 | 🚀 **Ракета** — откидывает лидера (если лидер ты — второе место) |
| 100–499 | 💥 **Супер-атака** — удар по двум соперникам + рывок |
| 500–999 | 🌪️ **Хаос** — все соперники буксуют 5 с |
| 1000+ | 👑 **Легенда** — кино на весь экран с аватаром донатера + огромный рывок |

Бесплатно: **лайки** заполняют шкалу страны (каждые 30 — рывок), **подписка** — щит команде, **репост** — рывок,
**вход в эфир** — аватар у машины своей страны.

Драма: раз в 30–45 с на дорожке лидера появляются **шипы или масло** (за 3 с — крупное предупреждение «Шипы впереди у 🇦🇲! Нужен щит!»):
без щита машина пробивает колесо или уходит в занос и теряет дистанцию, со щитом проезжает; **фотофиниш** с приближением камеры;
**капитан** страны (топ-донатер раунда) сидит за рулём в короне; **топ раунда и дня**; **герой раунда** на финише;
авто-комментатор говорит только о гонке.

## Графика

- 3D на Three.js (ставится через `npm install`, работает без интернета): ночной стадион с трибунами и флагами шести стран,
  трасса с разметкой и бордюрами, светофор F1 на старте, финишная арка с клетчатым флагом. Машины раскрашены целиком
  в цвета флага, номер на двери, колёса крутятся, кузов покачивается, тени и отражения.
- **Модели Kenney Car Kit (CC0):** положите `race.glb` в `public/race/assets/kenney/` — игра подхватит её сама
  (подробнее в README.txt в этой папке). Без файла используются встроенные машины.
- Шрифт Russo One лежит в `public/race/fonts/` (лицензия SIL OFL), иконки эффектов и картинки примерных подарков
  нарисованы в `public/race/icons.js`. Подарок для каждой плитки прайса задаётся в `config.json → race.tiers[].gift`
  (`name`, можно `image` — ссылка на картинку). Когда в эфире приходит настоящий подарок, его картинка из TikTok
  подставляется автоматически.
- **FPS:** панель показывает, сколько кадров в секунду рисует оверлей в LIVE Studio. Если меньше 50 — напишите,
  включу облегчённый режим.

## Модерация

- Текст из чата **никогда** не выводится на экран — только ник донатера и название эффекта.
- Ники проверяются по стоп-словам (`config.json → race.moderation`: русский, армянский, азербайджанский, турецкий,
  украинский, английский). Такой зритель на экране — «Зритель», без аватарки, и не попадает в топы и капитаны
  (подарки при этом работают). Список можно дополнять: `stopSubstrings` — части слов, `stopWords` — целые слова.
- Фразы комментатора — только шаблоны из `race.commentator` о скорости, обгонах и подарках.
- Никаких денежных призов и ставок, никаких фейковых подарков: при малом числе зрителей гонку оживляют базовая скорость, шипы и масло.

## Где что лежит

| Файл | Что это |
|---|---|
| `config.json → race` | страны, уровни подарков, длительность, стоп-слова, фразы комментатора, подсказки |
| `src/race/engine.js` | вся логика гонки (сервер считает, экран только рисует) |

| `data/race-day.json` | победы стран и топ дня (переживают перезапуск) |

Другие игры: `config.json → "game"`: `"race"` (по умолчанию), `"dragon"` (Давид против Вишапа, также `/dragon`),
`"outhouse"` (старая).

# Давид против Вишапа (игра с драконом)

Зрители всем эфиром сражаются с драконом-вишапом из армянских легенд.

- **Каждый зритель — воин.** Зашёл в эфир, написал в чат или лайкнул — на поле появляется воин с **его аватаркой** вместо лица.
- **Лайк** — воин кидает стрелу (лайками можно сбить жизнь дракона только до 10%).
- **Подарок** — удар, и чем дороже подарок, тем мощнее и зрелищнее удар:

| Удар | Цена | Подарок |
|---|---|---|
| 🏹 Стрела | от 1 монеты | Роза |
| 🔱 Копьё | от 5 | Finger Heart |
| ☄️ Огненный камень из катапульты | от 30 | Пончик |
| 🐎 Всадник с копьём | от 99 | Hand Heart |
| ⚡ **Давид Сасунский на коне Джалали с мечом-молнией** | от 299 | Корги |
| 🌠 Небесный огонь (метеоритный дождь) | от 1000 | Galaxy |

- **Последний удар** (только подарком) делает зрителя **Героем эфира**: его аватарка в короне на весь экран, салют, фанфары.
  Потом Вишап возвращается сильнее и другого цвета: изумрудный, огненный, теневой, ледяной, чёрный.
- ➕ Подписка = +30 урона, 🔁 «Поделиться» = вся армия даёт залп.
- Дракон дразнит зрителей голосом, иногда **сжигает армию огнём** (вернуться — лайкнуть), а если долго никто не бьёт, **лечится**.
- Справа «Топ урона», случайные **критические удары ×2**.

Запуск тот же: `npm start -- ВАШ_НИК_TIKTOK`, оверлей `http://localhost:3000/`, тест-панель `http://localhost:3000/?test=1`.
Голоса: `npm run voices` (у дракона низкий русский голос, у диктора — армянский `hy-AM-HaykNeural`).

Настройки — `config.json` → `dragon`: жизнь дракона (`baseHp`, `hpGrowth`), урон за монету (`damagePerCoin`),
шанс крита, урон лайков, удары и подарки (`attacks`), фразы дракона (`phrases`) и диктора (`announcer`).

Включить: `config.json` → `"game": "dragon"` или страница `http://localhost:3000/dragon`. Старая игра с будкой: `"game": "outhouse"` (или `/outhouse`).

# Старая игра: наказание за донат

Оверлей для эфира. Зритель дарит подарок, и персонаж (карикатура на политика в костюме, по умолчанию Эрдоган) в деревенском туалете получает наказание.
**У каждого наказания своя цена в монетах TikTok**, от самого дешёвого (яйцо в лоб) до «полного наказания».

| Наказание | Цена по умолчанию | Пример подарка |
|---|---|---|
| 🥚 Яйцо в лоб | от 1 монеты | Роза |
| 🍅 Помидор в лицо | от 5 | Finger Heart |
| 🍉 Арбуз в лицо | от 30 | Пончик |
| 🧱 Кирпич по голове | от 99 | |
| 💩 Ведро говна на голову | от 299 | |
| 🔥 Полное наказание (всё подряд) | от 1000 | |

Как выбирается наказание:
1. Если название подарка указано в поле `gifts` у наказания, срабатывает это наказание.
2. Иначе берётся **самое дорогое наказание, которое подарок «покрывает» по цене**.
   Например, подарок за 150 монет даёт кирпич, а за 5000 — полное наказание.
3. Серия подарков (роза ×3) даёт 3 удара подряд, но не больше `maxRepeatPerGift`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm start -- ВАШ_НИК_TIKTOK      # или впишите ник в config.json -> tiktokUsername
```

- Оверлей для эфира: `http://localhost:3000/`
- Тест без эфира (кнопки с ценами): `http://localhost:3000/?test=1`

### В TikTok LIVE Studio / OBS
Добавьте источник **«Браузер» (Browser source)** с адресом `http://localhost:3000/`, размер **1080×1920**.
Чтобы был слышен звук, включите «Управлять звуком через OBS».

### В TikTok LIVE Studio (Mac и Windows)
1. Вверху над списком источников выберите **вертикальный** режим (иконка телефона).
2. **Add source → Link** (или «Ссылка» / «Web»): адрес `http://localhost:3000/`, размер 1080×1920.
   Если такого пункта нет: откройте `http://localhost:3000/` в Chrome и добавьте **Display capture / Window capture**
   этого окна (на Mac LIVE Studio попросит разрешение «Запись экрана»).
3. Растяните источник на весь кадр.

## Табличка цен
Как в примере: **иконка подарка → наказание** (и цена в монетах). Картинки подарков берутся прямо из TikTok
после подключения к эфиру, до этого показываются эмодзи (`giftEmoji`). Какой подарок за что — поле `gifts`
у наказания (названия подарков TikTok на английском). `config.json` → `legend`: `lang` (`both`, `ru`, `arm`)
и `showPrice` (показывать ли цену).

## Настройка цен и наказаний: `config.json`

```jsonc
{
  "id": "egg",            // тип анимации: egg, tomato, watermelon, brick, poop
  "price": 1,             // минимальная цена подарка в монетах
  "emoji": "🥚",
  "title": "Яйцо в лоб",
  "titleArm": "Ձվով հարված դեմքին",
  "gifts": ["Rose"],      // подарки, которые всегда дают это наказание (англ. названия TikTok)
  "video": ""             // необязательно: свой ролик, например "media/egg.mp4"
}
```

Для «полного наказания» поле `combo` задаёт порядок анимаций.
Цены перечитываются на каждый подарок, так что перезапускать сервер после правки не нужно
(только обновите оверлей, чтобы обновилась табличка).

## Мимика

На каждое наказание у персонажа своя реакция:

| Наказание | До удара | После удара |
|---|---|---|
| 🥚 Яйцо | удивился, отклонился | злится, скрипит зубами |
| 🍅 Помидор | пытается увернуться | мотает головой «нет-нет», злится |
| 🍉 Арбуз | глаза по пять копеек | голову откидывает, плачет со слезами |
| 🧱 Кирпич | смотрит вверх | шишка, глаза-спирали, голова ходит кругами |
| 💩 Ведро | смотрит вверх, рот открыт | зеленеет, морщится, трясёт головой |
| 🔥 Полное | всё по очереди | в конце рыдает |

## Какой персонаж в будке

`config.json` → `character.model`: `"erdogan"` (по умолчанию) или `"putin"`.
Полный набор настроек и фраз для Путина лежит в `presets/putin.json`. Чтобы вернуть его,
скопируйте этот файл вместо `config.json` и запустите `npm run voices`.

## Обида на армян

Если подарок прислал зритель с армянской фамилией в нике (…yan, …ian, …ян, …յան), персонаж
с шансом 70% говорит особую обиженную фразу («Ахпер, ну за что?!»). Настройки в `config.json` → `armenian`:
`enabled`, `pattern` (по какому окончанию узнавать), `chance` (шанс от 0 до 1) и `phrases`.
В тест-панели можно ввести любой ник в поле «Ник», например `Petrosyan`, и проверить.

## Живой в покое

Пока никто не дарит, персонаж живёт своей жизнью: дышит, моргает, водит глазами, читает газету
и перелистывает страницы, закидывает ногу на ногу и качает ступнёй, оглядывается. Над газетой
он смеётся, удивляется, злится, зевает, подмигивает и косится в камеру, иногда комментируя это репликой.
Примерно раз в 20 секунд он сам что-нибудь говорит, чтобы подначить зрителей.

Настройки в `config.json` → `idle`:
- `talkEverySec`: как часто говорит сам (0 — молчит);
- `phrases`: общие фразы;
- `moods`: фразы для настроений (`surprised`, `laugh`, `grumpy`, `yawn`, `wink`, `suspicious`).

## Мемы и события
- ☕ пьёт турецкий чай из стаканчика-тюльпана, ☝️ «Ван минут!» с поднятым пальцем;
- 🐈 стамбульская кошка заходит в кадр, 🕊️ голубь гадит на голову, 🐔 по двору гуляет курица;
- **КОМБО ×N** — если подарки идут подряд, он умоляет пощадить (`config.json` → `combo`);
- **👑 Главные обидчики** — топ-3 донатеров эфира в правом верхнем углу (`leaders.enabled`).
Фразы для всего этого — `idle.moods` (`tea`, `oneMinute`, `cat`, `pigeon`) и `combo.phrases`.

## Голос

После каждого удара персонаж говорит реплику: появляется облачко с текстом, и шевелятся губы.
Реплики прописаны в `config.json` → `punishments[].phrases`:

```jsonc
"phrases": [
  { "text": "Это провокация!", "file": "" },                         // озвучка браузера
  { "text": "Кто кинул? Найти и наказать!", "file": "media/voice/egg2.mp3" } // свой файл
]
```

### Озвучка одной командой (бесплатно)

```bash
npm run voices
```

Скрипт озвучивает все фразы из `config.json` бесплатным нейро-голосом Microsoft
(по умолчанию `it-IT-GiuseppeMultilingualNeural`, мужской, говорит по-русски с итальянским акцентом), кладёт mp3 в `public/media/voice/auto/`
(пути запоминаются в `manifest.json` там же, `config.json` не меняется — обновления игры озвучку не сбрасывают). Нужен интернет. Если поменять или добавить фразу, запустите команду
ещё раз: озвучатся только новые.

Настройки голоса:
```bash
npm run voices -- --pitch -15Hz --rate -10%      # ниже и медленнее
npm run voices -- --list                          # какие голоса есть
npm run voices -- --voice ru-RU-SvetlanaNeural   # другой голос
npm run voices -- --engine mac                    # встроенный голос macOS (Yuri), без интернета
```

### Свои записи
Запишите реплики (свой голос или пародист), положите mp3 в `public/media/voice/` и укажите путь
в поле `file` у фразы. Такие файлы скрипт `npm run voices` не трогает.

Если своего файла нет, текст читает встроенный синтезатор браузера (`config.json` → `voice`).
Если нет и его, реплика просто показывается облачком.

Не рекомендуется клонировать нейросетью голос реального политика: TikTok помечает и удаляет
такие дипфейки и может заблокировать эфир.

## Свой персонаж и свои видео (как в AI-роликах)

Положите файлы в `public/media/` и пропишите их в `config.json`:

- `character.image`: картинка персонажа (`"media/hero.jpg"`), вертикальная 9:16;
- `character.idleVideo`: зацикленное видео, где персонаж просто сидит (`"media/idle.mp4"`);
- `character.faceX` / `faceY`: где на кадре лицо, в процентах (сюда летят яйца и остаются пятна);
- `punishments[].video`: готовый ролик наказания. Если он указан, вместо встроенной анимации
  играет ролик, а потом сцена возвращается к `idleVideo`.

Используйте только персонажей и изображения, на которые у вас есть права. Не используйте лица реальных людей без их согласия.
