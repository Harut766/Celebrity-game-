# Celebrity Game: наказание за донат в TikTok LIVE

Оверлей для эфира. Зритель дарит подарок, и персонаж (карикатура на политика в костюме) в деревенском туалете получает наказание.
**У каждого наказания своя цена в монетах TikTok**, от самого дешёвого (яйцо в лоб) до «полного наказания».

| Наказание | Цена по умолчанию | Пример подарка |
|---|---|---|
| 🥚 Яйцо в лоб | от 1 монеты | Роза |
| 🍅 Помидор в лицо | от 5 | Finger Heart |
| 🍉 Арбуз в лицо | от 30 | Пончик |
| 🧱 Кирпич по голове | от 99 | |
| 💩 Ведро говна на голову | от 299 | |
| 🔥 Полное наказание (всё подряд) | от 1000 | |

Как выбирается наказание:
1. Если название подарка указано в поле `gifts` у наказания, срабатывает это наказание.
2. Иначе берётся **самое дорогое наказание, которое подарок «покрывает» по цене**.
   Например, подарок за 150 монет даёт кирпич, а за 5000 — полное наказание.
3. Серия подарков (роза ×3) даёт 3 удара подряд, но не больше `maxRepeatPerGift`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm start -- ВАШ_НИК_TIKTOK      # или впишите ник в config.json -> tiktokUsername
```

- Оверлей для эфира: `http://localhost:3000/`
- Тест без эфира (кнопки с ценами): `http://localhost:3000/?test=1`

### В TikTok LIVE Studio / OBS
Добавьте источник **«Браузер» (Browser source)** с адресом `http://localhost:3000/`, размер **1080×1920**.
Чтобы был слышен звук, включите «Управлять звуком через OBS».

## Настройка цен и наказаний: `config.json`

```jsonc
{
  "id": "egg",            // тип анимации: egg, tomato, watermelon, brick, poop
  "price": 1,             // минимальная цена подарка в монетах
  "emoji": "🥚",
  "title": "Яйцо в лоб",
  "titleArm": "Ձվով հարված դեմքին",
  "gifts": ["Rose"],      // подарки, которые всегда дают это наказание (англ. названия TikTok)
  "video": ""             // необязательно: свой ролик, например "media/egg.mp4"
}
```

Для «полного наказания» поле `combo` задаёт порядок анимаций.
Цены перечитываются на каждый подарок, так что перезапускать сервер после правки не нужно
(только обновите оверлей, чтобы обновилась табличка).

## Свой персонаж и свои видео (как в AI-роликах)

Положите файлы в `public/media/` и пропишите их в `config.json`:

- `character.image`: картинка персонажа (`"media/hero.jpg"`), вертикальная 9:16;
- `character.idleVideo`: зацикленное видео, где персонаж просто сидит (`"media/idle.mp4"`);
- `character.faceX` / `faceY`: где на кадре лицо, в процентах (сюда летят яйца и остаются пятна);
- `punishments[].video`: готовый ролик наказания. Если он указан, вместо встроенной анимации
  играет ролик, а потом сцена возвращается к `idleVideo`.

Используйте только персонажей и изображения, на которые у вас есть права. Не используйте лица реальных людей без их согласия.

## Подключение к TikTok

Используется библиотека [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector).
Эфир должен быть запущен. Если TikTok ограничивает подключения, получите бесплатный ключ на eulerstream.com
и запустите с `EULER_API_KEY=ваш_ключ npm start -- ник`.
