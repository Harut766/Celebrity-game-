# Celebrity Game: наказание за донат в TikTok LIVE

Оверлей для эфира. Зритель дарит подарок, и персонаж (карикатура на политика в костюме, по умолчанию Эрдоган) в деревенском туалете получает наказание.
**У каждого наказания своя цена в монетах TikTok**, от самого дешёвого (яйцо в лоб) до «полного наказания».

| Наказание | Цена по умолчанию | Пример подарка |
|---|---|---|
| 🥚 Яйцо в лоб | от 1 монеты | Роза |
| 🍅 Помидор в лицо | от 5 | Finger Heart |
| 🍉 Арбуз в лицо | от 30 | Пончик |
| 🧱 Кирпич по голове | от 99 | |
| 💩 Ведро говна на голову | от 299 | |
| 🔥 Полное наказание (всё подряд) | от 1000 | |

Как выбирается наказание:
1. Если название подарка указано в поле `gifts` у наказания, срабатывает это наказание.
2. Иначе берётся **самое дорогое наказание, которое подарок «покрывает» по цене**.
   Например, подарок за 150 монет даёт кирпич, а за 5000 — полное наказание.
3. Серия подарков (роза ×3) даёт 3 удара подряд, но не больше `maxRepeatPerGift`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm start -- ВАШ_НИК_TIKTOK      # или впишите ник в config.json -> tiktokUsername
```

- Оверлей для эфира: `http://localhost:3000/`
- Тест без эфира (кнопки с ценами): `http://localhost:3000/?test=1`

### В TikTok LIVE Studio / OBS
Добавьте источник **«Браузер» (Browser source)** с адресом `http://localhost:3000/`, размер **1080×1920**.
Чтобы был слышен звук, включите «Управлять звуком через OBS».

### В TikTok LIVE Studio (Mac и Windows)
1. Вверху над списком источников выберите **вертикальный** режим (иконка телефона).
2. **Add source → Link** (или «Ссылка» / «Web»): адрес `http://localhost:3000/`, размер 1080×1920.
   Если такого пункта нет: откройте `http://localhost:3000/` в Chrome и добавьте **Display capture / Window capture**
   этого окна (на Mac LIVE Studio попросит разрешение «Запись экрана»).
3. Растяните источник на весь кадр.

## Табличка цен
Как в примере: **иконка подарка → наказание** (и цена в монетах). Картинки подарков берутся прямо из TikTok
после подключения к эфиру, до этого показываются эмодзи (`giftEmoji`). Какой подарок за что — поле `gifts`
у наказания (названия подарков TikTok на английском). `config.json` → `legend`: `lang` (`both`, `ru`, `arm`)
и `showPrice` (показывать ли цену).

## Настройка цен и наказаний: `config.json`

```jsonc
{
  "id": "egg",            // тип анимации: egg, tomato, watermelon, brick, poop
  "price": 1,             // минимальная цена подарка в монетах
  "emoji": "🥚",
  "title": "Яйцо в лоб",
  "titleArm": "Ձվով հարված դեմքին",
  "gifts": ["Rose"],      // подарки, которые всегда дают это наказание (англ. названия TikTok)
  "video": ""             // необязательно: свой ролик, например "media/egg.mp4"
}
```

Для «полного наказания» поле `combo` задаёт порядок анимаций.
Цены перечитываются на каждый подарок, так что перезапускать сервер после правки не нужно
(только обновите оверлей, чтобы обновилась табличка).

## Мимика

На каждое наказание у персонажа своя реакция:

| Наказание | До удара | После удара |
|---|---|---|
| 🥚 Яйцо | удивился, отклонился | злится, скрипит зубами |
| 🍅 Помидор | пытается увернуться | мотает головой «нет-нет», злится |
| 🍉 Арбуз | глаза по пять копеек | голову откидывает, плачет со слезами |
| 🧱 Кирпич | смотрит вверх | шишка, глаза-спирали, голова ходит кругами |
| 💩 Ведро | смотрит вверх, рот открыт | зеленеет, морщится, трясёт головой |
| 🔥 Полное | всё по очереди | в конце рыдает |

## Какой персонаж в будке

`config.json` → `character.model`: `"erdogan"` (по умолчанию) или `"putin"`.
Полный набор настроек и фраз для Путина лежит в `presets/putin.json`. Чтобы вернуть его,
скопируйте этот файл вместо `config.json` и запустите `npm run voices`.

## Обида на армян

Если подарок прислал зритель с армянской фамилией в нике (…yan, …ian, …ян, …յան), персонаж
с шансом 70% говорит особую обиженную фразу («Ахпер, ну за что?!»). Настройки в `config.json` → `armenian`:
`enabled`, `pattern` (по какому окончанию узнавать), `chance` (шанс от 0 до 1) и `phrases`.
В тест-панели можно ввести любой ник в поле «Ник», например `Petrosyan`, и проверить.

## Живой в покое

Пока никто не дарит, персонаж живёт своей жизнью: дышит, моргает, водит глазами, читает газету
и перелистывает страницы, закидывает ногу на ногу и качает ступнёй, оглядывается. Над газетой
он смеётся, удивляется, злится, зевает, подмигивает и косится в камеру, иногда комментируя это репликой.
Примерно раз в 20 секунд он сам что-нибудь говорит, чтобы подначить зрителей.

Настройки в `config.json` → `idle`:
- `talkEverySec`: как часто говорит сам (0 — молчит);
- `phrases`: общие фразы;
- `moods`: фразы для настроений (`surprised`, `laugh`, `grumpy`, `yawn`, `wink`, `suspicious`).

## Голос

После каждого удара персонаж говорит реплику: появляется облачко с текстом, и шевелятся губы.
Реплики прописаны в `config.json` → `punishments[].phrases`:

```jsonc
"phrases": [
  { "text": "Это провокация!", "file": "" },                         // озвучка браузера
  { "text": "Кто кинул? Найти и наказать!", "file": "media/voice/egg2.mp3" } // свой файл
]
```

### Озвучка одной командой (бесплатно)

```bash
npm run voices
```

Скрипт озвучивает все фразы из `config.json` бесплатным нейро-голосом Microsoft
(по умолчанию `it-IT-GiuseppeMultilingualNeural`, мужской, говорит по-русски с итальянским акцентом), кладёт mp3 в `public/media/voice/auto/`
(пути запоминаются в `manifest.json` там же, `config.json` не меняется — обновления игры озвучку не сбрасывают). Нужен интернет. Если поменять или добавить фразу, запустите команду
ещё раз: озвучатся только новые.

Настройки голоса:
```bash
npm run voices -- --pitch -15Hz --rate -10%      # ниже и медленнее
npm run voices -- --list                          # какие голоса есть
npm run voices -- --voice ru-RU-SvetlanaNeural   # другой голос
npm run voices -- --engine mac                    # встроенный голос macOS (Yuri), без интернета
```

### Свои записи
Запишите реплики (свой голос или пародист), положите mp3 в `public/media/voice/` и укажите путь
в поле `file` у фразы. Такие файлы скрипт `npm run voices` не трогает.

Если своего файла нет, текст читает встроенный синтезатор браузера (`config.json` → `voice`).
Если нет и его, реплика просто показывается облачком.

Не рекомендуется клонировать нейросетью голос реального политика: TikTok помечает и удаляет
такие дипфейки и может заблокировать эфир.

## Свой персонаж и свои видео (как в AI-роликах)

Положите файлы в `public/media/` и пропишите их в `config.json`:

- `character.image`: картинка персонажа (`"media/hero.jpg"`), вертикальная 9:16;
- `character.idleVideo`: зацикленное видео, где персонаж просто сидит (`"media/idle.mp4"`);
- `character.faceX` / `faceY`: где на кадре лицо, в процентах (сюда летят яйца и остаются пятна);
- `punishments[].video`: готовый ролик наказания. Если он указан, вместо встроенной анимации
  играет ролик, а потом сцена возвращается к `idleVideo`.

Используйте только персонажей и изображения, на которые у вас есть права. Не используйте лица реальных людей без их согласия.

## Подключение к TikTok

Используется библиотека [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector).
Эфир должен быть запущен. Если TikTok ограничивает подключения, получите бесплатный ключ на eulerstream.com
и запустите с `EULER_API_KEY=ваш_ключ npm start -- ник`.
